# نظام إصدار مستندات الشحن

تطبيق Flutter مكتبي يعمل محليًا لإعداد وطباعة فاتورة أجور الشحن وسند قبض الشيك.

## المزايا

- شاشة **بيانات الشركة** لتغيير الاسم والعنوان ووسائل التواصل بالعربية والإنجليزية، والسطرين الإضافيين، وعناوين الفاتورة والسند، والشعار.
- تخصيص مسميات خانات التوقيع في سند القبض. لا تُطبع خانات توقيع في فاتورة الشحن.
- زر **إنشاء سند من الفاتورة** يحفظ الفاتورة الحالية ثم ينقل اسم العميل والمبلغ الصافي والعملة ورقم الفاتورة والبيان إلى نموذج السند.
- زر **سحب بيانات فاتورة** في شاشة السند لاختيار فاتورة محفوظة وتعبئة بياناتها تلقائيًا.
- حفظ محلي باستخدام SQLite، وإنشاء ملفات PDF والطباعة دون خادم أو اتصال إنترنت أثناء الاستخدام.
- شاشة **العملاء والحسابات** لإدارة بطاقة العميل وبيانات التواصل والبحث وإيقاف/إعادة تفعيل البطاقة.
- إنشاء بطاقة العميل تلقائيًا عند حفظ أول فاتورة، وربط الفواتير وسندات القبض بمعرّف عميل ثابت.
- ترحيل الفاتورة كمدين وسند القبض كدائن في كشف العميل، مع فصل USD عن YER وعرض الرصيد المتحرك والفواتير غير المسددة.
- تخصيص سند القبض على الفاتورة المرتبطة تلقائيًا عندما يتطابق العميل والعملة؛ يدعم السداد الجزئي ويمنع تعديل عميل/عملة فاتورة بعد تخصيص دفعات بما يكسر الرصيد.
- ترقية قاعدة البيانات القديمة تلقائيًا مع استيراد الفواتير والسندات المحفوظة إلى حسابات العملاء دون حذف المستندات.

تُحفظ قاعدة البيانات والشعار داخل مجلد بيانات التطبيق على الجهاز. على Windows تكون قاعدة البيانات في `%APPDATA%\ShippingSystem\shipping_system.db`، كما يُنسخ الشعار المختار إلى هذا المجلد حتى لا يعتمد على مكان ملفه الأصلي.

## متطلبات التشغيل من المصدر على Windows

1. تثبيت Flutter SDK وإضافة مجلد `flutter/bin` إلى `PATH`.
2. تثبيت Visual Studio 2022 مع workload **Desktop development with C++** لبناء تطبيق Windows.
3. لتشغيل التطبيق من VS Code، تثبيت إضافتي Flutter وDart.

## التشغيل من Visual Studio Code

1. افتح مجلد المشروع `shippingSystem` في VS Code.
2. افتح الطرفية داخل المجلد وشغّل:

   ```powershell
   flutter doctor
   flutter pub get
   flutter run -d windows
   ```

3. أو اختر الجهاز `Windows (desktop)` من شريط VS Code واضغط `F5`.

## الاستخدام

- اختر **بيانات الشركة** أولًا وأدخل الترويسة، ثم اختر الشعار واضغط **حفظ الإعدادات**.
- من شاشة الفاتورة استخدم **إنشاء سند من الفاتورة** لنقل بيانات الفاتورة الحالية إلى سند جديد.
- من شاشة السند استخدم **سحب بيانات فاتورة** لاختيار فاتورة محفوظة.
- استخدم **العملاء والحسابات** لإدارة العملاء؛ سيظهر حساب العميل بعد حفظ أول مستند، واضغط بطاقته لعرض كشف الحساب والفواتير المفتوحة.
- استخدم **معاينة** لمراجعة المستند، و**طباعة** لإرساله إلى نافذة الطباعة، أو **حفظ PDF** لاختيار مكان الملف.
- تحفظ الطباعة وتصدير PDF نسخة من السجل محليًا. يتيح **فتح محفوظ** استرجاع المستند وتعديله.

## نطاق المحاسبة

هذه المرحلة تنفذ دفتر الذمم الفرعي للعملاء وربطه بالفواتير وسندات القبض. ليست بعدُ دفتر أستاذ عامًا مزدوج القيد أو نظام موردين ومصروفات وتقارير مالية؛ هذه وحدات لاحقة ينبغي أن تُبنى على مخطط حسابات وقيود متوازنة حتى لا تظهر أرصدة محاسبية مضللة.
