# نظام إصدار مستندات الشحن

تطبيق Flutter مكتبي يعمل محليًا لإعداد وطباعة مستندين:

- فاتورة أجور الشحن، بقالب أفقي.
- سند قبض شيك، بقالب أفقي أيضًا. الصورة المرجعية للسند ملتقطة بالاتجاه الرأسي، لذلك لا يعتمد التطبيق اتجاه الصورة.

يُحفظ سجل الفواتير والسندات في قاعدة SQLite على الجهاز. لا يحتاج التطبيق إلى خادم أو اتصال إنترنت أثناء الاستخدام. ملفات PDF وخطوط Noto Naskh العربية مضمّنة في التطبيق.

## المتطلبات على Windows

1. تثبيت Flutter SDK وإضافة مجلد `flutter/bin` إلى `PATH`.
2. تثبيت Visual Studio 2022 مع workload **Desktop development with C++** لبناء تطبيق Windows.
3. تثبيت Visual Studio Code وإضافتي Flutter وDart.

## التشغيل من Visual Studio Code

1. افتح مجلد المشروع `shippingSystem` في VS Code.
2. افتح الطرفية داخل المجلد وشغّل:

   ```powershell
   flutter doctor
   flutter pub get
   flutter run -d windows
   ```

3. أو اختر الجهاز `Windows (desktop)` من شريط VS Code واضغط `F5`.

## الاستخدام

- اختر «فاتورة أجور الشحن» أو «سند قبض - شيك» من القائمة الجانبية.
- أدخل البيانات. يمكن إضافة أكثر من بند مالي في فاتورة الشحن.
- استخدم «معاينة» لمراجعة المستند، و«طباعة» لإرساله إلى نافذة الطباعة، أو «حفظ PDF» لاختيار مكان الملف.
- يستخدم «حفظ سجل» قاعدة البيانات المحلية. كما تحفظ عمليتا الطباعة وتصدير PDF نسخة محلية من السجل، ويتيح «فتح محفوظ» استرجاع المستند وتعديله.

على Windows تُحفظ قاعدة البيانات داخل `%APPDATA%\ShippingSystem\shipping_system.db`.

## ملاحظات القالب

أُعيد بناء القالب اعتمادًا على صور WhatsApp المتاحة. تمت محاكاة ترتيب الحقول والألوان والعناوين، لكن المطابقة الطباعية الدقيقة إلى مستوى كل بكسل تحتاج إلى نسخة أصلية واضحة أو PDF ممسوح ضوئيًا دون ميل، إضافةً إلى ملف الشعار الأصلي وبيانات الشركة النهائية. يمكن تعديل أبعاد الصفحة والخطوط والحدود بسهولة داخل `lib/services/pdf_service.dart`.
